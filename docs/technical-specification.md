# Техническое задание

## 1. Назначение и область применения
Система предназначена для учёта запросов покупателей на отсутствующие размеры и модели в одном розничном бутике Adidas. Область применения: работа продавцов и управляющего в течение смены.

## 2. Роли и права
| Роль | Права |
|---|---|
| Продавец | создание, просмотр, изменение статуса, комментирование запросов |
| Управляющий | всё, что продавец, плюс управление пользователями, просроченные запросы, выгрузка отчётов |

## 3. Функциональные модули
1. Аутентификация и управление пользователями (FR-10, FR-11)
2. Запросы покупателей: создание, статусы, история, комментарии, отмена (FR-01–04, 08, 13)
3. Поиск и фильтрация (FR-05, 06)
4. Контроль просрочки (FR-07)
5. Шаблоны сообщений покупателю (FR-09)
6. Отчёты (FR-12)

## 4. Сущности данных
- **User** (id, имя, логин, хэш пароля, роль, активен)
- **Request** (id, артикул, размер, имя покупателя, телефон, статус, создан, обновлён, автор, причина отмены)
- **RequestEvent** (id, request_id, автор, тип, старый статус, новый статус, комментарий, время)

Связи: User 1—N Request (автор); Request 1—N RequestEvent; User 1—N RequestEvent.

## 5. Внешние интеграции
В первой версии отсутствуют (см. Out of scope).

## 6. Технологический стек
| Компонент | Выбор | Обоснование |
|---|---|---|
| Backend | Python + FastAPI | быстрая разработка, автодокументация API, знакомый язык |
| БД | PostgreSQL | реляционная модель с чёткими связями, надёжность, бесплатный |
| Frontend | React + адаптивная вёрстка | работа со смартфона и ПК из одной кодовой базы |
| Развёртывание | Docker Compose на VPS | простое воспроизводимое окружение, низкая цена |
| Резервное копирование | pg_dump по cron | покрывает NFR-05 без дополнительных сервисов |

## 7. Ограничения и допущения
- Нагрузка: один бутик, до 15 одновременных пользователей.
- Бюджет и сроки уточняются у заказчика.
- Персональные данные покупателей (имя, телефон) хранятся минимально необходимый срок, доступ только у авторизованных сотрудников.
- Допущение: заказчик согласует хранение телефонов вне корпоративных систем сети.
