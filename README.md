# SizeDesk — учёт запросов на отсутствующие размеры

Веб-приложение для сотрудников розничного бутика Adidas: фиксирует запросы покупателей на товар, которого нет в зале или на складе точки, и ведёт их до выдачи или отказа.

**Для кого:** управляющий и 10 продавцов-консультантов одного бутика.
**Проблема:** сейчас запросы записываются в мессенджере и на бумаге, часть теряется, покупателей не уведомляют вовремя.
**Заказчик:** управляющий бутика (команда 10 человек). Персональные данные не раскрываются.
**Автор:** Карибаев Диас
